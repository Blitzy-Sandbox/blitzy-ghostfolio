# Dashboard Refactor — Implementation Decision Log

This log captures every non-trivial implementation decision made during the refactor that transforms Ghostfolio's route-per-screen navigation into a single-canvas, user-composable modular dashboard — introducing the `angular-gridster2` drag-and-drop grid engine, a plugin-style module registry, a grid canvas rendered at the root route `/`, per-user layout persistence, a searchable module catalog, and a 12-column grid with a fixed (constant-px) row height and a 2×2 minimum module size. It satisfies the AAP § 0.8.4 **Explainability** rule, which mandates that every non-trivial implementation decision be documented with rationale (decision, alternatives, why, risks) in a Markdown decision-log table. Decision identifiers use the `DL-` prefix scoped to this document — deliberately distinct from the `D-001..D-023` identifiers in the pre-existing `docs/decisions/agent-action-plan-decisions.md` and from Decision D-020 (Technical Specification § 1.2), which is referenced verbatim wherever cited. This document is a **sibling** of `docs/traceability-matrix.md` and complements — but does not replace — the pre-existing `docs/decisions/agent-action-plan-decisions.md`.
